SQLGuard MCP — a safety envelope for agent access to SQL warehouses

A guard that sits between an agent and the warehouse. It proves a query only reads by walking the whole parse tree rather than checking its root — which is what catches a DELETE hidden inside a CTE. Against 46 attacks and 30 legitimate analytics queries it gives 0 bypasses and 0 false alarms in 0.11 ms, where prefix and denylist guards leak 26–37%. Around that: dry-run cost ceilings, row filters injected into the AST, cursored results, and an audit log that records refusals with the agent's stated intent.
